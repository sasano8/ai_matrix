Chrome built-in AI について

対応するデスクトップ版 Chrome の Prompt API（LanguageModel）を使用します。HTTPS または localhost と、日本語対応モデルが必要です。初回はモデルのダウンロードが発生します。利用できない場合は Chrome の対応状況・設定と端末の空き容量を確認してください。

解析する文章はこのアプリから外部サーバーへ送信しません。サンプルは操作確認用の固定データです。AI の出力には誤りが含まれることがあります。
