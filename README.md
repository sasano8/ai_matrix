# AI Matrix

Chrome built-in AI の Prompt API で、ひとつの投稿を複数の観点に整理するフロントエンドアプリです。マトリクスは見出しだけのコンパクト表示です（標準・詳細モードは未実装で選択不可）。観点ごとに独立した深掘りカードを追加でき、選択したカードの話題・観点・本文を横幅を広げた右側のページに表示します。元の投稿は話題の下から開閉できます。

## 今後の構想

工程ごとのマトリクスをつなぐ思考パイプライン、成果物から入力へのフィードバック、入力ファイルの保持については、[思考パイプライン構想](docs/thought-pipeline.md) に記録しています。これらは今後の実装要件であり、現行アプリの機能ではありません。

## ローカルで起動

ビルドや依存関係のインストールは不要です。

```sh
cd /workspace/ai_matrix
python3 -m http.server 8000 --bind 127.0.0.1
```

Chrome で localhost のポート8000にアクセスしてください。静的ファイルを直接開くより、ローカルサーバーを使うことを推奨します。

## 思考の方向性と編集

投稿ボタンは「思考をひらく」です。その横の小さな選択欄から生成プロンプトを選べます。「プロンプト・設定」を開くと、実際に送るプロンプトを確認・編集できます。投稿本文が主役となるよう、設定は通常折り畳んでいます。

- **問いかける（初期値）**：本人が自分で考えるための問いを生成します。
- **整理する**：事実・気持ち・未確認の点を分けて整理します。
- **可能性を広げる**：異なる見方を仮説として広げます。
- **提案する**：具体的なアイデア・助言を理由や注意点とともに示します。
- **計画する**：目標を行動・順序・確認項目に落とします。
- **自由に指定**：自分でプロンプトを書けます。

観点レベル・深掘りレベルの初期値はそれぞれ **3** です。件数の目安であり、上限ではありません。足りない場合は一度追加の補完を試みます。重複する見出しは追加せず、有益な内容を思い浮かばなければ少ないままや空の結果も受け入れます。補完で既存の編集内容を置き換えることはありません。生成のプロンプトとレベルは投稿時に保存し、そのマトリクスの追加の展開にも同じ設定を使います。設定の変更は次の投稿の生成に適用します。以前の結果は自動で再生成しません。

「深掘りする」は同じ観点を縦に掘り下げ、「視野を広げる」は新しい観点を横に追加します。どちらにも任意の切り口を入力できます。新たな候補がなければ、既存の結果を残してその旨を表示します。

ソートの「ロングテール」「プライオリティ」はフォーカス・マウスオーバー・クリックで説明を表示するだけです。重要度の採点や並べ替えは未実装です。プライオリティは各深掘りの重要度の合計、ロングテールは目立ちにくい少数の観点に着目する並びを想定しています。

右の「ページを編集」から話題、観点、深掘りの見出し・本文を変更し、「自分の考え・答え・計画」に自分の言葉を追記できます。「変更を保存」でマトリクスにも反映します。話題は全体に、観点の見出しは同じ列に反映されます。編集内容と自分の考えは次の深掘りの文脈にも含まれます。未保存の変更がある状態でカードを切り替えると、破棄の確認が出ます。

## Chrome built-in AI

`LanguageModel.availability()` / `LanguageModel.create()` / `session.prompt()` を使います。Chrome 内部の文法制約エラーを避けるため、`responseConstraint` は渡さず、JSON Schema を通常のテキストプロンプトに含め、アプリ側で JSON を解析・検証します。コードフェンス付きの JSON も受け入れ、解析できなければ形式修正を一度試みます。日本語・英語の入力と日本語の出力を宣言しています。利用には日本語モデルを扱える対応デスクトップ版 Chrome、HTTPS または localhost、モデルのダウンロードに必要な通信・空き容量が必要です。対応ハードウェア・地域・Chrome 設定などは [公式ガイド](https://developer.chrome.com/docs/ai/prompt-api) を確認してください。API が提供されない環境では解析ボタンを無効にして案内を表示します。サンプルは固定データで、実際の AI 回答と明確に区別しています。

投稿・結果・方向性・編集内容・自分の考え・深掘り入力は、このブラウザの localStorage に保存します。別の投稿の解析が成功すると置き換わります。履歴一覧やサーバーへの送信はありません。保存内容を削除するには、このサイトのサイトデータを Chrome の設定から削除してください。共有端末での機密情報の入力には注意してください。AI 出力は事実確認が必要です。

生成中は「生成を中止」からキャンセルできます。各モデル呼び出しには180秒のタイムアウトがあります。失敗や中止時には投稿・保存済みの結果・追加質問を保持し、画面にエラーを表示します。この対策が実端末のモデル内部エラーを解消するかは、対応する Chrome 上での確認が必要です。

## GitHub Pages

`.github/workflows/pages.yml` が main への push で静的ファイル3点をデプロイします。リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** に設定してください。サイトは通常 `https://sasano8.github.io/ai_matrix/` になります。相対パスで読み込むためサブパスに対応しています。API キーやバックエンドは不要です。

## 検証

`node --check app.js` で構文を確認できます。ブラウザの機能テストは `tests/browser.cjs` にあります。Playwright と Chromium を用意し、ローカルサーバーの起動後に `node tests/browser.cjs` を実行します。システムの Chromium を使う場合は `CHROMIUM_PATH=/usr/bin/chromium node tests/browser.cjs` を実行してください。Prompt API をモックしたテストは UI・リクエスト構成・エラー復旧を検証します。実際の端末内モデルによる生成品質やダウンロードは、対応する Chrome 上で別途確認してください。
